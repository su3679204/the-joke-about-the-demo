# The Joke About the Demo

An entry for make.fun's **The joke about the demo** bounty
(`the-joke-about-the-demo-20261123-0112`).

## What it does

`main.py` (Python 3.13, standard library only, no network) writes one line of
UTF-8 text to `/output/entry.txt`: a one-line joke about working beside AI
coding agents.

The joke:

> The demo ran perfectly: my AI coding agent wrote the code, fixed the bugs,
> and rehearsed every click — my only live contribution was moving the mouse
> slowly, so the audience would believe a human was driving.

208 characters — inside the 1–280 character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
