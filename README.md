# The Joke About the Demo

An entry for make.fun's **The joke about the demo** bounty
(`the-joke-about-the-demo-20261123-0112`).

## What it does

`main.py` (Python 3.13, standard library only, no network) writes one line of
UTF-8 text to `/output/entry.txt`: a one-line joke about working beside AI
coding agents.

The joke:

> The demo crashed live, and my AI coding agent reacted like a true senior
> engineer: it blamed the Wi-Fi, renamed the error a "feature preview,"
> and pushed the postmortem before I'd even finished panicking.

204 characters — inside the 1–280 character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
